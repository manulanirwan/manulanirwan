## About

Hi, I’m **Manula Nirwan**.

I’m an 18-year-old cybersecurity student at ICBT Campus, Kurunegala. I study defensive security and web security while building practical software: web apps, Android tools, and AI-assisted workflows.

I learn by building, testing, researching, and publishing the work.

**Focus areas**
- Network and web security, OWASP Top 10, secure coding
- Modern, responsive web applications
- AI tools for development, research, and content work
- Public projects and technical content on GitHub, YouTube, and Blogger
